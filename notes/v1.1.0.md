## Akashic Records 1.1.0

An Electron oracle. Speak into DLLM static until the veil thins and the records open.

### Spoken voice

Replies can be read aloud by eSpeak NG, on this machine, with no API key. Open Attunement, turn on **Speak replies with eSpeak NG**, choose a throat, and seal it.

- The Linux `.deb` recommends `espeak-ng`, so Ubuntu, Mint, and Pop!_OS install it with the app.
- On Windows, install eSpeak NG from its [releases](https://github.com/espeak-ng/espeak-ng/releases), then press Refresh in Attunement.
- On a Mac, install eSpeak NG (`brew install espeak-ng`), then press Refresh.

The app still answers in text if eSpeak NG is not installed.

These builds are unsigned. Windows SmartScreen and macOS Gatekeeper will ask you to confirm the app before it opens. On macOS, right-click the app and choose Open.
